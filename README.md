# Amazon Laptop Scraper

This project scrapes laptop listings from Amazon using Python, Requests, and BeautifulSoup.

The scraper extracts the following information:

* Image URL
* Product Title
* Rating
* Price
* Ad / Organic Result

The extracted data is stored in a Pandas DataFrame and exported to a CSV file with a timestamp in the filename.

## Requirements

* pandas
* requests
* beautifulsoup4

## Output

The output is a CSV file containing the scraped laptop data.
